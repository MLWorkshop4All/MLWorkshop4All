# MLWorkshop4All

This repository contains the code and materials for a web-based self-driving vehicle simulator to increase AI literacy. The goal is to promote public understanding and trust in AI by visually and interactively demonstrating the real-world impacts of flawed datasets. The simulator leverages models trained in Google’s Teachable Machine to illustrate the effects of data imbalance, bias, and poisoning through observable behavior in traffic scenarios.

Participants use the simulator to train and evaluate TensorFlow image classifiers on deliberately flawed datasets involving traffic signs (stop, yield, do-not-enter). As the vehicle navigates a 2D city map, users see how models behave when trained on unbalanced, biased, or poisoned data—and then iteratively improve the datasets to address these issues. Designed for learners with minimal technical background, this tool supports scalable, experiential learning and fosters critical thinking about AI ethics, trustworthiness, and responsible data practices.

This repository includes three example datasets and the source code needed to host the simulator. The hosted site, [mlworkshop4all.org](https://mlworkshop4all.org/), provides a live demo and is hosted at no cost using Cloudflare Pages' free tier.
